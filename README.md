# GeoGPT 智能助手 - 前端交互界面

一个现代化的前端轻量大模型交互网站，通过GeoGPT API提供智能对话服务。

## 功能特点

- 🎨 **现代化界面设计** - 简洁美观的聊天界面，支持亮色/暗色主题
- 💬 **实时对话** - 流畅的聊天体验，支持多轮对话
- ⚙️ **可自定义设置** - 调整模型参数（temperature、max_tokens等）
- 📱 **响应式设计** - 完美适配桌面端和移动端
- 🔐 **安全可靠** - 安全的API调用，支持多种认证方式
- 📝 **富文本支持** - 支持Markdown格式，代码高亮
- 💾 **本地存储** - 自动保存用户设置和对话历史

## 文件结构

```
├── index.html          # 主页面
```

## 快速开始

### 1. 下载文件

将所有文件下载到本地目录。

### 2. 配置API

根据您的GeoGPT API信息，修改 `script.js` 文件中的配置：

```javascript
const API_CONFIG = {
    baseUrl: '您的API地址',              // 替换为实际的API地址
    apiKey: 'sk-z75090H521z8f37O3973',    // 您提供的API密钥
    apiName: 'CUG_key_first',            // 您提供的API名称
    model: 'gpt-3.5-turbo',              // 根据实际情况调整
    timeout: 30000
};
```

详细配置说明请参考 [API_CONFIG.md](./API_CONFIG.md)

### 3. 运行网站

#### 方法1：直接打开文件
双击 `index.html` 文件在浏览器中打开。

#### 方法2：使用本地服务器（推荐）
```bash
# 使用Python的简单HTTP服务器
python -m http.server 8000

# 或使用Node.js的http-server
npx http-server -p 8000

# 然后在浏览器中访问 http://localhost:8000
```

## 使用说明

### 基础功能

1. **发送消息** - 在输入框中输入问题，点击发送按钮或按Enter键
2. **查看历史** - 所有对话记录会显示在聊天区域
3. **清空对话** - 点击垃圾桶图标清空所有对话记录
4. **调整设置** - 点击齿轮图标打开设置面板

### 高级设置

点击设置按钮可以调整以下参数：

- **回答创造性 (Temperature)**: 0-1之间，数值越高回答越有创造性
- **最大回复长度**: 100-4000之间，控制AI回复的最大字符数
- **系统提示词**: 设置AI的角色和行为规则

### 快捷键

- `Enter` - 发送消息
- `Shift + Enter` - 换行
- `Esc` - 关闭设置面板

## 界面预览

### 主界面
- 顶部显示GeoGPT智能助手标题和连接状态
- 中间是聊天消息区域，支持滚动查看历史记录

## 故障排除

### 常见问题

1. **无法连接API**
   - 检查API配置是否正确
   - 确认网络连接正常
   - 查看浏览器控制台错误信息

2. **CORS跨域问题**
   - 使用本地HTTP服务器而不是直接打开文件
   - 确认API服务器支持CORS

3. **API密钥无效**
   - 验证API密钥格式是否正确
   - 确认API密钥是否已激活

### 调试方法

1. 打开浏览器开发者工具 (F12)
2. 查看Console标签页的日志输出
3. 检查Network标签页的API请求状态
4. 根据错误信息进行相应调整
